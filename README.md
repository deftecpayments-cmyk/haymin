# موقع هميان HIMYAN

موقع بطاقة الدفع الوطنية «هميان» — عربي وإنجليزي.

## الصفحات
| الصفحة | عربي | إنجليزي |
|---|---|---|
| الرئيسية | index.html | index-en.html |
| طلب البطاقة | order.html | order-en.html |
| ملخص الطلب | summary.html | summary-en.html |
| لوحة التحكم | admin.html | (نفس الصفحة) |

## التشغيل محلياً
```
npm start
```
ثم افتح http://localhost:3000

## النشر على Railway
1. ارفع كل الملفات على مستودع GitHub.
2. من Railway: New Project ← Deploy from GitHub repo، واختر المستودع.
3. Railway يتعرّف على المشروع من package.json ويشغّل `npm start`.
4. من Settings ← Networking اضغط Generate Domain للحصول على رابط.

## لوحة التحكم
افتح `/admin.html`. كلمة المرور الافتراضية: `himyan2026` (غيّرها من متغير `ADMIN_PASSWORD` في Railway).
اللوحة تعرض طلبات إصدار البطاقة فقط: الاسم، الجوال، الرقم الشخصي، البنك، البطاقة، الساعة، وحالة الطلب، مع زر تفاصيل وتغيير الحالة (جديد/قيد المعالجة/تم الإصدار/تم التسليم/ملغي). تتحدث تلقائياً كل 5 ثوانٍ.

## إعدادات Railway المهمة
1. **كلمة المرور:** من Variables أضف `ADMIN_PASSWORD` بكلمة قوية.
2. **حفظ الطلبات:** Railway يمسح الملفات مع كل نشر. من Settings أضف Volume على مسار `/data` وأضف متغير `DATA_DIR=/data`، وإلا تضيع الطلبات.

## ملاحظات مهمة
- زر اللغة ينقل بين النسخة العربية والإنجليزية مع الحفاظ على البطاقة/الساعة المختارة.
- فورم الطلب يرسل بيانات مقدّم الطلب فقط (الاسم، الرقم الشخصي، الجوال، البنك، العنوان) إلى `/api/orders`. لربط قاعدة بيانات، عدّل نقطة الاستقبال في `server.js`.
- الموقع لا يلتقط ولا يخزّن أي بيانات بطاقة بنكية أو CVV أو OTP أو رقم سري. لتفعيل الدفع الفعلي، استخدم بوابة دفع مرخّصة (مثل QPay/Dibsy في قطر أو Stripe/Checkout.com) حيث تذهب بيانات البطاقة للبوابة مباشرة.
- الروابط في الفوتر (الشروط، الخصوصية، اتصل بنا) لم تُفعّل بعد.
- استخدام شعار مصرف قطر المركزي و Apple Pay و Visa/Mastercard يتطلب تصاريح رسمية قبل النشر الفعلي.
